The default palette is now Apple's, from the macOS 27 kit: accent `#0088ff` / `#0091ff`, danger `#ff383c` / `#ff4245`, and neutral label colours (`rgba(0, 0, 0, 0.85)` and `0.5` in light, `rgba(255, 255, 255, 0.85)` and `0.55` in dark) in place of the blue-tinted ones. A theme that sets these tokens itself is unaffected.
