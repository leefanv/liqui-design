Thirty-seven components, most of them a `LiquiGlass` surface with a Base UI
primitive driving it. A few deliberately are not — a
[separator](/docs/components/separator) is one pixel wide and has no room for a
bezel, a [fieldset](/docs/components/fieldset) would only be a lens for the
lenses inside it to bend — and those pages say why, because knowing where the
material stops is part of using it.

Every tile below is the real component rendering the real material. Open one to
try it, read what is specific about putting it on glass, and copy the source
`shadcn add` writes into your project.

<Callout type="info">
  Refraction renders in Chromium. In Safari and Firefox these tiles fall back to
  frosted blur automatically, which is worth seeing too — see
  [Glass](/docs/handbook/glass#degradation).
</Callout>

## Installing

Any one of them is a single command, and the first one you add brings the glass
design tokens with it:

```bash
npx shadcn@latest add https://liqui.design/r/button.json
```

See [Quick start](/docs) for the namespace setup if you are adding several.
